# 满满音乐 · 功能说明

全部功能都是**纯客户端**实现：不需要自建服务器、不需要买云主机，只用免费公共服务做中转。

| 用途 | 服务 | 是否需要注册 |
| --- | --- | --- |
| 哔哩哔哩登录 / 取音源 / 收藏夹 | B 站官方 web 接口 | 用你自己的 B 站账号 |
| 一起听同步 | ntfy.sh（公共 pub/sub） | 不需要 |
| 检查更新 | GitHub Releases API | 不需要 |

---

## 界面结构

底部三个入口：

```
首页          一起听          设置
```

迷你播放器固定在三个 tab 的正上方（以前它浮在 tab 同一高度，想切页或收起播放页都得先上滑，已经改掉）。

### 历史播放

记录真正播放过的歌，最多 100 条。长按进入多选，可以批量删、单条删。

### 我的歌单

**只有一张歌单：满满音乐。**

以前是「我喜欢 + 收藏夹 A + 收藏夹 B」的列表，点进去还要先选歌单；
现在打开「我的歌单」直接就是满满音乐的歌曲列表，能播放、能删。

- 播放页点红心 → 进满满音乐
- 在别处「添加到歌单」→ 直接进满满音乐（不再弹选择框）
- 顶部三个动作：播放全部 / 同步 B 站 / 清空

## 收藏夹导入与同步

进入「设置 → 哔哩哔哩账号 → 从收藏夹导入」。

- **导入** = 把这个收藏夹里「满满音乐还没有」的视频补进去，只增不删
- **同步** = 再跑一次导入，拉收藏夹里新加的视频
- **不做自动同步**：不会在后台偷偷请求接口，也不会把你手动删掉的歌塞回来
- 只在本机记「哪些收藏夹同步过、上次什么时候同步」

这样即使哪天不用这个 App 了，B 站上的收藏夹还是原样，歌一首不少。

## 一起听

### 房间号

房间号就是你的 B 站 UID：`bili_你的UID`。登录后打开 App 会自动上线（设置里可关），
朋友在「一起听」页看到你在听歌，点一下就能进。

### 权限

| 角色 | 条件 | 权限 |
| --- | --- | --- |
| 房主 | 自己上线 | 换歌、暂停、拖进度 |
| 共管 | 在名单里 + 被点红心 | 和房主一样 |
| 听众 | 在名单里，没点红心 | 只能听，播放控制被锁 |
| 路人 | 不在名单里 | 被拒绝，进不来 |

- 名单是**空的起步**，从「我关注的人」里手动挑，不会把几十个 UP 主全塞进来
- 名单里点红心 = 共管；再点一下取消
- 听众想自己点歌，先退出房间
- 房主把某人移出名单，会立刻把他请出房间

### 提示与音效

- 有人加入 / 离开：Toast 提示 + 一声很轻的提示音（上行两音 / 下行两音）
- 提示音单独用一个低音量播放器，和音乐混在一起，不打断播放
- 设置里可以关掉

### 掉线与退出

- 听众每 10 秒心跳一次；40 秒没动静就从成员列表移除
- 房主下线会广播 `bye`，听众收到后立刻退出并提示「房主下线了」
- 房主异常退出（杀进程）时，听众 45 秒后自动退出
- 不会再有「他明明下线了，房间列表里还挂着」的幽灵房间

## 数据库

单库 `musicOrder`，v3 起只有三张歌单表：

| 表 | 用途 |
| --- | --- |
| 满满音乐 | 唯一的歌单，红心和导入都进这里 |
| 本地 | 本地音乐（保留） |
| 待播放列表 | 临时队列 |

从 v2 升级时自动迁移：`我喜欢` 改名并合并，所有 `收藏夹_xxx` 表合并后删除。
这也是修掉「收藏夹导入报 table already exists」和「只能导入一首」的根本办法——
以前每个收藏夹单独建表，表名取自标题，重名或标题为空就建表失败；
导入的条目还缺 `playId`，播放链算不出来，列表里就只剩一首能放。
